Como usar

Cada snippet é um arquivo .js independente. Você pode:

1. Via CDN (jsDelivr)

<script src="https://cdn.jsdelivr.net/gh/designfas/js-snippets/tabs/tabs.js"></script>

2. Copiando o arquivo para o seu projeto

<script src="./js/tabs.js"></script>

Todos auto-inicializam no DOMContentLoaded com defaults razoáveis. Se quiser customizar, cada um expõe uma função init(options) que retorna um destroy() — veja a documentação de cada snippet.

Dica: em produção, prefira fixar uma versão no jsDelivr (@v0.1.0) quando houver releases publicadas.
